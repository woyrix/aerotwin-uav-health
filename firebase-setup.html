AAEROTWIN FIRST-RUN GUIDE

Connect Aerotwin

Firebase handles account sign-in and private fleet storage. Woyrix uses the demo Gemini key configured in the app.

  1. Configure Firebase

    Enable Authentication → Email/Password and create Cloud Firestore. Publish the rules in firestore.rules. Add localhost and your Vercel domain under Authentication → Settings → Authorized domains.

  2. Configure Gemini for the demo

    For local use, put your demo key in the ignored gemini-config.js file. For Vercel, set GEMINI_API_KEY under Project Settings → Environment Variables and use npm run build. The generated browser config is visible to website users. Use a restricted key with a low quota, then revoke it after the hackathon.

  3. Deploy to Vercel

    Import the GitHub repository. Choose the repository root, Framework Preset Other, build command npm run build, and output directory .. Vercel builds and serves the static site, so your PC does not need to stay on after deployment.

Firebase web config: Keep the Web app settings in the format export const firebaseConfig = { … }. These are client settings; never paste Gemini keys into firebase-config.js.

This prototype uses estimated/simulated data and is not an aircraft maintenance or flight-safety authority.
