AAEROTWIN FIRST-RUN GUIDE

Connect Aerotwin services

Firebase provides account sign-in and private fleet storage. Woyrix uses a Firebase-hosted function so the Gemini key stays on the server.

  1. Configure Firebase

    Create a Firebase project and Web app. Enable Authentication → Email/Password, create Cloud Firestore, and publish firestore.rules. Add localhost and your Vercel domain under Authentication → Settings → Authorized domains.

  2. Install and select the Firebase CLI project

    Install Node.js 22 and Firebase CLI. In the Aerotwin folder run firebase login, then firebase use --add and select the same project as firebase-config.js.

  3. Set your private Gemini key once

    Revoke any Gemini key that was shared in a chat, screenshot, source file, or public repository. Create a replacement in Google AI Studio, then run firebase functions:secrets:set GEMINI_API_KEY. Paste the replacement only into the CLI's hidden prompt; it is stored in Google Secret Manager and is not added to app files or GitHub.

  4. Deploy Woyrix's backend

    From this folder run firebase deploy --only functions. The callable function requires Firebase sign-in, reads only that account's fleet, limits request rate, and sends prompts to Gemini. Cloud Functions deployment requires the Firebase project to use the Blaze plan; Google may charge for function and model usage.

  5. Deploy the website to Vercel

    Import the GitHub repository in Vercel. Use the repository root as the project root, with no build command and . as the output directory. Deploy the function separately with Firebase CLI as above. Once both are deployed, Vercel serves the website and Firebase runs Woyrix; your PC can be off.

Keep the key private: Never paste the Gemini key into app.js, firebase-config.js, Vercel client-side variables, a browser form, or GitHub. The Firebase Web app configuration is public client configuration; the Gemini key belongs only in Firebase Secret Manager.

This prototype uses estimated/simulated data and is not an aircraft maintenance or flight-safety authority.
