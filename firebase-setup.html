AAEROTWINFIRST-RUN GUIDE

Connect your Firebase project

Firebase provides username/password sign-in and keeps each account’s aircraft list private to that account.

  1. Create a Firebase project

    Open the Firebase Console, create a project, then add a Web app from Project settings.

  2. Add the web app configuration

    Copy the Firebase web app config into firebase-config.js, replacing the YOUR_… placeholders. Restrict the Firebase API key to your app’s domains in Google Cloud when deploying.

  3. Enable email and password sign-in

    In Firebase Console, open Authentication → Sign-in method and enable Email/Password. On Aerotwin’s sign-in screen, use Create account; the entered username is mapped to username@aerotwin.app.

  4. Create Firestore and apply account rules

    Create a Cloud Firestore database. In its Rules tab, publish the contents of firestore.rules. The rule allows a signed-in user to read and write only under their Firebase UID.

  5. Run Aerotwin

    Open a terminal in the Aerotwin folder and run python -m http.server 8000. Visit http://localhost:8000, then create an account or sign in.

Woyrix / Gemini: Create a Gemini API key in Google AI Studio, open Woyrix in the dashboard, and paste the key under API key. The key stays in page memory only. Chat requests include every aircraft’s available status and telemetry, sent to Gemini; the hidden data is not rendered into the chat transcript.

This prototype uses estimated/simulated data and is not an aircraft maintenance or flight-safety authority.
